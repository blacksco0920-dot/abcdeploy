# ABCDeploy 内部实施资料

本目录不是产品文档，只保存实现新产品时确实需要查询的工程材料。

## 使用顺序

任何人或 AI 必须先阅读：

1. [产品合同](../product-contract.md)；
2. [工程架构](../architecture.md)；
3. 当前任务对应的前端规范或验收标准。

只有在开始修改代码后，才能按需阅读：

- [当前实现迁移清单](implementation-inventory.md)：定位可复用能力、旧入口和迁移缺口；
- [CodeGraph 指南](codegraph.md)：查询定义、调用者、影响范围和受影响测试。

## 隔离规则

- 本目录中的旧页面、旧字段、具体 Provider 和兼容模型都不是产品需求。
- 不得把迁移难度、已有数据结构或 Provider 能力反向写进产品合同。
- 产品页面需要的新概念必须先在产品合同中成立，不能从本目录推导。
- 历史讨论和已废弃方案不在此保留，需要追溯时使用 Git。
